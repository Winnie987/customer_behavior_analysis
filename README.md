# customer_behavior_analysis
Data analytics project showcasing customer behavior analysis using python, sql and power Bi.
Customer Shopping Behavior Analysis
Overview

This project analyzes customer shopping behavior using transactional data from 3,900 purchases across various product categories. The goal is to uncover insights into spending patterns, customer segments, product preferences, and subscription behavior to guide strategic business decisions.

The workflow covers the full analytics pipeline from data cleaning and exploratory analysis in Python, to SQL-based querying, to an interactive Power BI dashboard, and finally a business report and presentation summarizing key findings and recommendations.


# Dataset
Size: 3,900 customer transactions
Fields include: customer demographics (age, gender), product category, purchase amount, discount usage, subscription status, shipping type, review ratings, and purchase frequency
Format: CSV


# Tools & Technologies

Python: Data cleaning, exploratory data analysis (EDA), visualization (Pandas, NumPy, Matplotlib/Seaborn)

SQL: Query and analyze data using PostgreSQL, MySQL, or SQL Server

Power BI: Interactive dashboard for visual reporting

Jupyter Notebook: Development environment for analysis


# Project Steps

Data Loading: Import the raw dataset into Python using Pandas

Data Cleaning: Handle missing values, correct data types, and standardize formatting

Exploratory Data Analysis (EDA): Analyze distributions, correlations, and trends across customer and product attributes

SQL Analysis: Load the cleaned dataset into a relational database and run queries to answer specific business questions (e.g., top-selling categories, high-value customer segments)

Dashboard Development: Build an interactive Power BI dashboard to visualize key metrics and trends

Reporting: Summarize findings and actionable insights in a written report


# The Power BI dashboard provides an interactive view of:

Revenue and purchase trends by category, age group, and season

Customer segmentation (e.g., loyal vs. occasional buyers)

Subscription status and its impact on purchase behavior

Discount usage and its effect on sales volume

Shipping preferences and their correlation with spending

# Key Results & Recommendations

Boost Subscriptions: Promote exclusive benefits for subscribers

Customer Loyalty Programs: Reward repeat buyers to move them into the "Loyal" segment

Review Discount Policy: Balance sales boosts with margin control

Product Positioning: Highlight top-rated and best-selling products in campaigns
